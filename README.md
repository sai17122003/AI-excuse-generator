# 🤖 AI-Excuse Generator  
An AI-powered app to generate smart, funny, or realistic excuses — perfect for dodging awkward moments with style.
## 📦 Features
- 💬 Generate believable or humorous excuses with a single click
- 🔊 Voice-based playback with pre-recorded MP3s
- 🎯 Simple, fast, and efficient — no complex AI/ML dependencies
- 🌐 Hosted for free on Hugging Face Spaces
- 🎨 Clean Streamlit interface
- ## 🛠 Tech Stack
- **Frontend**: Streamlit
- **Backend**: Python 3.x
- **Deployment**: Hugging Face Spaces
- **Audio**: Pre-generated `.mp3` files

---

## 🧠 How It Works
The app randomly picks excuses from a curated list and optionally plays a corresponding audio message. While it doesn’t currently use NLP or deep learning, its modular design supports AI integration later.
